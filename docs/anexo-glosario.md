# Anexo. Glosario Maven

**Al finalizar podrás:** consultar el vocabulario esencial del curso.

| Término | Significado |
|---|---|
| Artefacto | Archivo producido o consumido por una construcción |
| GAV | `groupId`, `artifactId`, `version` |
| POM | Modelo XML del proyecto Maven |
| Repositorio local | Caché de artefactos descargados e instalados |
| Maven Central | Repositorio público de artefactos |
| Dependencia transitiva | Dependencia requerida por otra dependencia |
| Scope | Alcance de una dependencia |
| Plugin | Extensión que aporta tareas Maven |
| Goal | Objetivo concreto de un plugin |
| Phase | Etapa de un ciclo de vida |
| Lifecycle | Secuencia de fases de construcción |
| SNAPSHOT | Versión de desarrollo |
| Surefire | Plugin habitual para pruebas unitarias |
| Shade | Plugin para ensamblar JAR con dependencias |
| Wrapper | Scripts que facilitan usar una versión fijada de Maven |
| Reactor | Mecanismo de Maven para construir varios módulos |
| Perfil | Conjunto de configuraciones activables |
| BOM | POM de gestión de versiones de bibliotecas |
